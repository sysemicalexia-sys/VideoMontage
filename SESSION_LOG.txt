================================================================================
Design decisions worth remembering
================================================================================
1. AIDE drove everything: Groovy DSL, Java 8 language level, ndk-build,
   single module, only two Maven deps (appcompat, recyclerview), JSON via
   built-in org.json, no Compose/Kotlin anywhere.
2. The old multi-module Kotlin tree (phase 1) was discarded entirely once
   the AIDE constraint arrived — nothing in the repo references it.
3. JNI boundary is dumb by design: parallel primitive arrays in, GL out.
   All business logic is C++; all UI coordination is Java.
4. Three motion systems, one property each: zoom spring, playhead spring,
   scroll OverScroller. Nothing ever snaps except by explicit user intent.
5. Undo is snapshot-based because the model is immutable — the snapshot is
   a track-list copy and clips are shared, so 64 levels cost almost nothing.
6. Native frame memory is a fixed arena (FramePool) + generation-tagged LRU
   (FrameCache). Decoder drops frames under pool pressure instead of
   allocating; scrub smoothness beats completeness mid-drag.
